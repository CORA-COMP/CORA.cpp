# Differences from CORA

Where CORA.cpp deliberately differs from CORA's MATLAB code, because CORA's result is wrong or unsound, or lists the same set in the order of the CORALean oracle.

| CORA file | What CORA does | What CORA.cpp does | Minimal input |
|---|---|---|---|
| `contSet/@interval/atan2.m` | Returns the hull of `atan2` at the four corners, which misses +-pi across the branch cut | Follows CORALean's guarded definition: the corner hull if `0 < inf x`, `0 < inf y` or `sup y < 0`, else [-pi, pi] rounded outward | `y = [-1, 1]`, `x = [-2, -1]`: CORA gives [-2.678, 2.678] |
| `contSet/@interval/boundaryPoint.m` | For a box unbounded on one side, `Inf*0 = NaN` enters the bound, and `x(inf_dirs) = Inf*sign_dir(d_inf)` uses the wrong mask, so it returns +-Inf | Returns the exit point of the ray; +-Inf only where the ray never leaves (coordinates with `dir = 0` keep `start`) | `I = [0, Inf]`, `dir = -1`, `start = 1`: CORA gives -Inf, the exit point is 0 |
| `contSet/@interval/acosh.m` | The out-of-domain error says the valid domain is '>= -1 && <= 1' | The domain is `>= 1`, as the code checks; the message says so | `acosh(interval(0.5, 2))` |
| `contSet/@interval/enlarge.m` | For a box unbounded on one side and `factor = 1`, `center` is NaN and the bounds become NaN | Keeps the bounds: scaling by 1 is the identity | `I = [0, Inf]`, `factor = 1`: CORA gives `[NaN, NaN]` |
| `contSet/@interval/isIntersecting_.m` | Loops `for i = 1:length(I)` over the linear index, so for an interval matrix only the first max(rows, columns) entries are compared and a disjoint later entry is missed | Compares every entry | `I = interval(zeros(2), ones(2))`, `S = interval([0 5; 0 5], [1 6; 1 6])`: CORA gives true |
| `contSet/@zonotope/lift_.m` | Projects onto `proj` (`project(Z, proj)`), which is the inverse permutation of what `lift` documents (state `i` goes to position `proj(i)`); the two agree only where `proj` is its own inverse | Puts state `i` at position `dims[i]`, as `lift` of intervals and polytopes does | `Z = zonotope([1;2;3])`, `proj = [2 3 1]`: CORA gives (2;3;1), CORA.cpp (3;1;2) |
| `contSet/@zonotope/encloseMany.m` | Reduces each set with `reduce(Z, 'parallelpiped')`, a method `reduce` does not have, so it fails with `CORA:wrongValue` | Reduces to order 1 (Girard), as CORALean's definition does | `encloseMany({zonotope([0;0], eye(2))}, [1;0])` |
| `contSet/@zonotope/enclosePoints.m` | `'maiga'`: when the compression vector `g` vanishes (all points equal, or the first singular vector orthogonal to the box radius), `u = g / norm(g)` is `0/0` and the points become NaN | Skips the compression, so the cloud is unchanged and still enclosed | `enclosePoints([1 1 1; 2 2 2])` |
| `contSet/@zonotope/isIntersecting_.m` | For points, calls `contains_(Z, S, type, tol, false, false)` with six arguments where `contains_` takes seven, and fails | Answers with `contains` of all points, up to `tol` | `isIntersecting(zonotope([0;0], eye(2)), [0;0])` |
| `contSet/@zonotope/norm_.m` | `'exact'` maximizes `\|G u\|` over `u in {-1,1}^m` and returns the norm of `c + G u`, which is not the maximum norm for `c ~= 0` | Refuses `'exact'` (it needs a mixed-integer solver) | `Z = zonotope([10; 0], [1 0; 0 1])`: the maximizer ignores `c` |
| `contSet/@interval/rdivide.m` | For a number over a box with `sup = 0`, returns `[-Inf, n/inf]` whatever the sign of `n`, which misses every value for `n < 0`; a denominator `[0, 0]` has its NaN overwritten, giving `[-Inf, n/0]` | Returns the ray `[n/inf, Inf]` for `n < 0`; refuses `[0, 0]` with `CORA:outOfDomain`, as the NaN check intends | `n = -1`, `D = [-2, 0]`: CORA gives `[-Inf, 0.5]`, the quotients are `[0.5, Inf)` |
| `contSet/@interval/representsa_.m` | `'capsule'` and `'ellipsoid'` count the coordinates of width zero (`<= 1`), so every full-dimensional box is both | At most one coordinate with a nonzero width, as CORALean's counterexample requires | `I = [0,1] x [0,1]`, `'capsule'`: CORA gives true |
| `contSet/@fullspace/isequal.m` | Tests `all(infimum(S) == -Inf) && all(supremum(S) == Inf)` for an interval `S`, which is true for an empty interval (bounds `zeros(n,0)`: `all` of nothing), so the whole space equals the empty set (read from the source, not run) | Compares with the box `(-Inf, Inf)^n`; an empty interval is not equal | `isequal(fullspace(2), interval.empty(2))`: CORA gives true |
| `contSet/@fullspace/center.m` | Returns `NaN` in R^0, as MATLAB has no vector of length 0 | Returns the empty column (0, 1), as CORALean does | `center(fullspace(0))`: CORA gives NaN |
| `contSet/@fullspace/lift_.m` | Does not check `dims`: its length or range is never used | Refuses a `dims` of the wrong length or outside [0, N) with `CORA:wrongValue`, as `Interval::lift` | `lift_(fullspace(2), 3, [0])`: CORA gives `fullspace(3)` |
| `contSet/@contSet/decompose.m` | For one block it returns `S.copy()`, the whole set (and a set, where several blocks give a cell array), whatever the block names | Projects onto the block, as CORALean's definition does and as CORA does for several blocks | `S = interval([0;0;0], [1;1;1])`, `blocks = [1 2]`: CORA gives the three-dimensional `S` |
| `contSet/@zonotope/split.m` | `split(Z)` and `split(Z,N)` split `zonotope(interval(Z))`, which drops the generators of flat coordinates, so `N` counts the coordinates of nonzero width: it splits another coordinate or fails | `N` is the coordinate; both halves of a flat coordinate are the box | `Z = zonotope([0;0],[1;0])`, `split(Z,2)`: CORA fails with an index beyond the one generator |
| `contSet/@zonotope/splitFirstGen.m` | Passes the index of the generator with the largest score to `split(Z,index)`, which reads it as a coordinate of the box around `Z` | Splits that generator of `Z`, as CORALean's definition does | `Z = zonotope([1;1],[1 0.1 0; 0 0.1 3])`: CORA halves the box at coordinate 3, which does not exist |

| `contSet/@fullspace/supportFunc_.m` | Returns `Inf` for every direction, also `dir = 0`, where the supremum of `0'x` over R^n is 0 | Returns 0 along the zero direction and `Inf` along any other, as CORALean proves (`Fullspace.supportFunc_eq`) | `supportFunc(fullspace(2), [0;0])`: CORA gives Inf |

| `matrixSet/@intervalMatrix/private/priv_intervalMatrixRemainder.m` (in `expmDifferentAlgorithms.m`, `expmTaylorHornerScaling.m`) | The Taylor remainder of a point matrix (`inf == sup`) is `intervalMatrix(ones(n), 0) * f`, the point `f` (`f` the remainder bound), not the box `[-f, f]` of the other branch, so the result excludes `exp(A)` | The remainder is `[-f, f]` for every matrix | `intervalMatrix(-1)`, order 2, style 0: CORA gives the point 13/18 = 0.722, `exp(-1)` = 0.368 |
